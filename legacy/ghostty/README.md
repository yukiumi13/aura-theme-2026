# Archived Ghostty variants

These files preserve the Ghostty bundle from Aura Modern 0.9.7, before the
current nine-theme lineup was ported. They are frozen compatibility files and
are not regenerated or included in new Ghostty bundles.

The maintained configurations are in `packages/ghostty`. Use a theme's full
filename (including `.conf`) in Ghostty's `theme` setting. Existing copies in
your Ghostty themes directory are not removed by the new bundle.
