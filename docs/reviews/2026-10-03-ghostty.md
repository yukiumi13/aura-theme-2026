## Scope and evidence

Baseline: Aura Modern 0.9.7, commit `d2422b7f6aec5587a974d8a5261fb88d1727be6c`. This is a local Ghostty update, not a new VS Code release.

Read all nine decoded Ghostty configurations: 14 color fields and 16 ANSI slots per theme, **270 values total**. Also inspected all 24 mode-specific Herdr override values. Complete outputs and LF-normalized SHA-256 hashes are in [resolved-ghostty.json](resolved-ghostty.json). [The HTML sheet](resolved-ghostty.html) contains configuration specimens and every resolved value; it is not a real terminal screenshot.

The existing VS Code review generator was run across 4,500 UI entries, 432 TextMate rules and 270 semantic tokens. All nine generated theme files are identical to the accepted baseline after normalizing line endings. The generated manifest, stylesheet and effect inventory also have no Git content changes. This verifies preservation, not a new runtime review of VS Code.

**Accepted choices:** retain all nine accepted ANSI palettes and semantic roles. Background, foreground and every ANSI slot exactly match each theme's VS Code terminal. Cursor and active search may use a different ink than the corresponding VS Code button: terminal glyphs are small, and the ink is selected from existing neutral palette endpoints. No source hue was darkened or desaturated. Ghostty themes expose neither the reference's claim-all gradient nor the VS Code glow roles.

**Herdr compatibility correction:** its `terminal` theme uses ANSI 8 as an active-row/hover fill. For Aqua Light, normal text `#4A5861` on `#80919A` is 2.25:1. The optional Aqua companion maps existing list roles to `active_row_bg = #E9F3F6`, `selection_bg = #E1EEF1`, and `surface1 = #ECF1F5`: corresponding default-text ratios are 6.51, 6.19 and 6.46. These are existing resolved UI relationships. ANSI 8 remains available as readable gray text ink in other terminal applications.

Herdr's status/notification colors, default text, backgrounds and primary accent continue to inherit its `terminal` theme. In particular its primary accent uses ANSI 4, so Aqua Light's Herdr accent is `#4A80A7`, not `#12DADD`. The adapter makes no promise to copy VS Code's filled-control appearance. Existing `surface_dim` and secondary foreground behavior remain Herdr-owned and need real UI assessment.

**Role correction during review:** the first companion draft reused terminal text-selection fills. Aura Dark's selection expects the stronger selected-text foreground, while Herdr keeps normal text. The final adapter uses the actual list/list-focus/hover roles instead. This both matches their semantics and preserves readable normal text across all families; no base color changed.

The binary and libraries were unpacked into a temporary directory; nothing was installed system-wide.

- TypeScript typecheck, ESLint on changed code, and Git whitespace checks passed.
- All **283 tests in 16 suites** passed, including 17 Ghostty/Herdr-specific tests for source/output equality, lineage, full terminal parity, alpha compositing and companion roles.
- Local ZIP contains exactly nine `.conf` files, four Herdr TOML files, README, MIT license and third-party notices. All 16 file payloads matched their sources byte-for-byte, and Python's independent ZIP integrity test passed. - All 26 old Ghostty configurations remain available under `legacy/ghostty` and match the baseline. No user configuration was edited or removed.

## Coverage gaps

This is a full resolved-color review and runtime **parser** check. No actual Ghostty/Herdr window was visually inspected on this host. The browser inspection tool timed out, so even the generated specimens are not being reported as visually verified. Remaining checks include real Herdr selected/hovered rows and modal contrast, macOS native titlebar behavior, GTK titlebars, dim/bold rendering, native search and selection, split opacity, and live light/dark switching with existing sessions. Configuration contrasts are evidence of particular pairings, not proof of whole-screen aesthetic quality.

Conclusion: the compiled hierarchy is consistent with the accepted family designs, and the concrete ANSI-gray surface mismatch has an optional role-based remedy. The package is ready for local trial, with desktop visual verification still outstanding.
