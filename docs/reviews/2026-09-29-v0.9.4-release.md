# Aura Modern 0.9.4 release verification

Date: 2026-09-29. Prepared for Marketplace publication at the user's request.
The previous public release is 0.8.0. Builds 0.9.0–0.9.3 were local previews;
their final changes are consolidated into the 0.9.4 changelog.

## Scope

- Nine themes and their existing selection IDs remain available.
- Aqua Light and Aqua Lime Light gain optional primary-button and numeric
  activity-badge gradients. Their plain UI uses white button edges, mint
  selection accents, and a neutral title separator.
- Enhanced buttons have distinct normal, hover and keyboard-focus states.
  Numeric markers use a vertical cyan-to-green fill, white edge and small glow.
- Effects compile through source colors, independent UI roles, the adapter,
  and the VS Code renderer. Registration and roles determine their scope.
- The desktop enhancement is off by default. README setup instructions explain
  the separate loader, installation-wide behavior, reloads and editor-update
  limitations. Tabs and syntax are outside its scope.
- README previews form one continuous gallery; optional setup follows the
  Modern UI section.

## Design conclusion and limits

The complete [resolved-effect review](2026-09-29-effect-roles.md) and
[parity record](2026-09-29-effect-roles/parity.json) apply unchanged. The final
release preserves the inspected cyan-led buttons, compact mint/green markers,
white edges and cool reading surfaces. The review's stated gaps for fresh
native Classic UI, keyboard focus, multi-digit badges, separate Aqua Light
and CSS-off rendering remain. Release preparation is not additional native
visual coverage.

All newly committed review screenshots were inspected for personal content.
They show isolated fictional samples and generic editor notifications, and
remain review evidence rather than Marketplace gallery assets.
