# Aura Modern 1.0.0

Aqua Lime Light pairs a white editor, active tab and terminal with a near-white frame (#FBFBFB). The selected file retains pale aqua (#E9F3F4) while the editor has focus. Hovering another file produces a gray row (#E9E9E9). In the checked Linux VS Code 1.144.1 profile, focused and unfocused selection, active and inactive windows, keyboard focus and tab-close hover remained distinguishable.

[VS Code capture with the selected file](../assets/aura-aqua-lime-light-v1.png) · [Complete resolved theme inventory](resolved-themes.html)

The stable VSIX was rebuilt on the v0.9.8 source baseline and compared with the accepted local 0.9.12 preview. All nine theme files, the optional enhancement CSS and extension JavaScript matched byte for byte. The effect inventory changed only in its version field. The VSIX passed archive integrity checks and has no Marketplace prerelease flag. TypeScript and all 324 tests passed.

Only Aqua Lime Light's VS Code theme changed relative to v0.9.8. The shared reading surfaces also reach the maintained Zed, Kitty and Ghostty outputs. The native visual review covered VS Code in an isolated fictional workspace with Modern UI on and optional CSS off. Classic keyboard focus was also checked. Remote/SSH and TOML-specific highlighting were reviewed in configuration only.
