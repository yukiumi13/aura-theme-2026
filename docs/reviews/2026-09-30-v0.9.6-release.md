# Aura Modern 0.9.6 release verification

Date: 2026-09-30. Release requested after the unified focus-role preview and
architecture review. Baseline: published 0.9.5 (`bf53bde`).

## Scope and design conclusion

The shared focus role now covers eligible inputs, primary buttons, toolbar
icons and notification toasts in Aqua Light and Aqua Lime Light. It uses the
accepted cyan/mint/green reference anchors, with control, compact and surface
glow densities. Notification surfaces yield to focused child controls.
Action fill, hover, badge attention, severity and validation remain independent.

The detailed resolved-config review and remaining native visual coverage are
recorded in `2026-09-30-notification-focus.md`. Release preparation introduces
no additional palette or interaction changes. The user responded positively
to the revision and requested publication; this is not recorded as a complete
visual state-matrix inspection. Computer Use remained unavailable during the
preview review, so no new native screenshots are claimed.
