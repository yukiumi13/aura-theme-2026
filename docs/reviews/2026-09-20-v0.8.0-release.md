# Aura Modern 0.8.0 release verification

Date: 2026-09-20. Prepared from `feat/aqua-lime-light` at the user's request.

## Release scope

- Nine VS Code themes, adding Aura Aqua Lime Light with the accepted Sample C
  syntax. Its complete UI and terminal palette are inherited from Aqua Light.
- Aqua Light retains its published syntax palette. Existing selection IDs remain
  compatible. Experimental A-D study themes are excluded from the VSIX.
- Shared Aqua/Lime translucent toolbar hover preserves the active cyan tab under
  its white close icon. Modern UI mappings, modified-tab colors, chart purple,
  and consistent TextMate boolean/enum fallbacks accompany the new theme.
- README and changelog describe the ninth theme. Root and VS Code package
  versions are 0.8.0; other editor ports are not rebuilt by this release.

## Verification

- Rebuilt the VS Code port and regenerated the resolved-theme inventory.
- All nine generated payload SHA-256 values match the previously inspected
  [design review manifest](2026-09-20-aqua-lime/manifest.json) exactly. The release
  preparation changes metadata only; it does not alter accepted theme colors.
- All 13 repository test suites pass: **249 tests**.
- ESLint passes for every changed TypeScript source and test file. The existing
  test helper's line endings and property formatting were normalized.
- The versioned VSIX includes nine theme JSON files, the manifest, README,
  changelog, logo, license, and third-party notices. It contains no study helper
  extension or demo workspace.
- The local commit hooks require an unavailable `yarn` executable. Their lint
  and commit-message checks are run directly with the repository's installed
  ESLint and commitlint before committing.

## Design conclusion and limits

The accepted summer syntax and native hover correction are unchanged from the
[Aqua Lime design review](2026-09-20-aqua-lime-review.md). That review covers CSS,
TSX, Markdown/embedded JSON, active and inactive tab actions, and surrounding
Explorer surfaces in the isolated fictional workspace. Its documented gaps for
fresh Classic UI, keyboard focus, dark hover, and other secondary states remain;
this release check does not represent a new full native visual review.
